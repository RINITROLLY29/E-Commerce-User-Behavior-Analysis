# E-Commerce User Behavior Analysis Dashboard

A Power BI dashboard analyzing customer behavior and sales trends in an e-commerce platform.

## Tools Used
- Power BI
- Power Query
- DAX

## Key Insights
- Total Sessions
- Total_Revenue
- Revenue_Per_User
- Aug_Session_Duration
- Bounce_Rate
- High_Engagement
- Unique_Visitors
- returned_amount
